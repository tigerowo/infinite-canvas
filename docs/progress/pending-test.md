# 待测试

## 生成媒体与图生图

- 验证画布和生图工作台的生成图片会保存到服务端本地存储，卡片使用缩略图，打开原图时支持长期缓存。
- 验证 JPEG、PNG、WebP 等参考图在文件扩展名或浏览器 MIME 声明不准确时仍可正常进行图生图。
- 验证 Agnes 图生图会把同源或私网参考图转换为 Data URI，并按官方参数返回 URL 结果。
- 验证视频任务在刷新或关闭页面后继续由后端轮询，遇到限流时按 `Retry-After` 退避，完成后保存到本地存储并支持 Range 播放。
- 验证已完成的图片任务在新会话和历史列表中仍能恢复预览。
