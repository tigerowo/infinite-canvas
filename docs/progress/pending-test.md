# 待测试

- 生成前确认框已接入画布、生图台、视频台和重试入口，正式请求前显示渠道、模型、任务类型和协议；连接中心用户渠道在云端模式下也应显示真实渠道名称且不暴露凭据。
- 视频、画布图片和画布音频任务对外统一为 `queued`、`running`、`succeeded`、`failed`、`cancelled`、`timed_out`；旧状态读取时兼容归一。
- 三类任务新增显式取消接口；活动视频或图片被删除时会先传播取消。视频陈旧轮询结果不能覆盖已取消状态，画布请求继承可取消上下文。
- 火山方舟 Seedance 的排队视频任务取消会在本地落状态前向官方 `DELETE /contents/generations/tasks/{id}` 传播；RunningHub Provider 新增 `POST /providers/:id/runninghub/tasks/:taskId/cancel` 并调用官方 `/task/openapi/cancel`。两者使用受限响应预算、既有 SSRF 安全客户端与脱敏日志，远端失败不阻断本地取消；其他未公开正式取消协议的供应商不会猜测调用。
- 画布图片、视频和音频运行节点，以及生图台、视频台的运行任务卡新增独立“取消任务”按钮；任务创建阶段按钮暂时禁用，取消后保留记录并显示“已取消”，不再依赖删除记录触发取消。
- 画布图片和音频任务增加 5 分钟总体 deadline，并在代理写入内存时限制 32 MiB 响应；视频任务继续使用 30 分钟、360 次和 32 MiB 累计预算。
- 图片、视频和音频取消服务新增 Vitest 契约覆盖，检查编码后的任务路径、POST 方法、登录鉴权、成功响应和业务失败响应；按项目约束本轮仅补测试文件，尚未执行测试命令。
- 用户渠道携带凭据时只允许同源重定向；Base URL 用户信息、fragment、私网解析和自定义 Header CR/LF 注入继续被拒绝。
- 401、403、429 和 5xx 使用固定安全错误映射；普通日志、AI 调用日志和任务错误详情会脱敏 Bearer、API Key、Token、Secret 与常见供应商密钥格式。
- 画布、生图台和视频台的模型选择已统一合并系统公共渠道与连接中心用户 Provider；云端模式下用户 Provider 使用 `X-User-Model-Channel-ID`，系统渠道继续使用 `X-Model-Channel-ID`，退出登录会清除托管目录，未登录旧本地配置仍可继续使用。
- OpenAI 兼容、Gemini 原生与通用 HTTP adapter 已通过本地 Mock 模型列表契约；通用 HTTP 使用原样 Base URL 和标准业务路径，支持 Bearer 或自定义请求头鉴权。
- Mock 失败场景覆盖无效 JSON、鉴权失败、超大响应和请求超时；RunningHub、`gpt-image-2`、OpenOx Gemini 图片兼容模型、Gemini 原生文本模型与通用 HTTP 文本模型均已完成真实任务。
- OpenAI 兼容 Chat 生图现可提取 `choices[].message.content` 中 Markdown 包裹的图片 Data URL；任务响应和错误详情保存前会摘要长 Base64。已用真实 OpenOx 返回结构补充 Go 与 Vitest 回归测试，重启 Go 后端后的 UI 成功态已人工确认。
- 生图工作台结果区增加成功、生成中和失败计数，生成图片按完整比例展示，任务卡强化状态辨识；连接中心增加连接、已连接和请求防护概览。需继续人工检查桌面与窄屏布局、浅色与深色主题。
- 生图台浮动工作流按钮的服务端与浏览器首次渲染使用同一初始坐标，客户端恢复已保存位置后再显示，避免位置差异触发 hydration warning 或出现首屏闪跳。
- 已成功但未同步的临时 Data URL 在刷新后保留成功记录，并显示“临时结果未同步”说明；不再使用红色失败占位误导用户。长期保留仍需在刷新前同步到云端或保存到素材库。
- 连接中心执行“测试并拉取模型”后，会立即把刷新后的模型列表和默认模型同步回当前编辑表单，不再需要关闭抽屉后重新打开才能选择模型。
- Gemini 原生已使用官方端点完成一次连接测试和一次模型拉取。`gemini-2.5-flash-lite` 的首次请求因上游不再向新用户开放而失败且未自动重试；用户再次确认后，`gemini-3.5-flash-lite` 最低成本文本请求返回 `OK`、`STOP`，真实生成链路通过。
- 通用 HTTP 已使用 OpenOx 完成一次连接测试和一次模型拉取；`gemini-3.5-flash` 的 8-token 请求无可见文本，用户确认后的 64-token 请求遇到一次上游 `EOF`，再次确认后的 128-token 请求返回 `OK`、`stop`。每次请求均独立确认，没有自动重试。
- Provider 只修改默认模型时不再清除最近连接状态；协议、Base URL、密钥或请求头变化仍会重置为 `untested`。修复前已经被重置的本地 Gemini 状态不会伪造恢复，本轮仍不重复测试上游。
- 连接中心 `/providers` 已在隔离 SQLite 中完成登录后桌面与 390px 窄屏人工回归；后续收到正式 STITCH 实稿后仍需做像素级复核。
- 旧 `localChannels` 的只读迁移预览、精确去重、事务导入，以及可选的旧明文密钥清理与渠道 ID 替换；迁移不会测试连接或请求真实 API。
- API Provider 新增、编辑、复制、启停、设为默认、删除及历史引用冲突提示。
- API Key 与自定义请求头留空保持原值，接口和页面不返回明文；显式清空行为待补充 UI 入口后验证。
- 登录用户选择托管 Provider 后，生图、视频、音频和画布请求继续通过 `X-User-Model-Channel-ID` 使用现有调用链。
- 用户 Base URL 访问私网、回环、链路本地、CGNAT 或危险重定向时被拒绝。
- 图片代理拒绝 HTML/SVG 和超过 25 MiB 的响应；AI 代理拒绝 HTML/SVG、超过 128 MiB 的请求和超过 512 MiB 的响应。
- WebDAV 与 S3/R2 容量统计共享每次操作 256 请求、64 MiB、2 分钟预算；WebDAV 使用迭代目录队列，S3 拒绝重复分页标记和无效容量。
- 单分类及全量提示词同步限制为 32 请求、32 MiB、2 分钟；全量同步的所有分类共享预算，超限后不替换未完整完成的分类。
- 工作流 Agent 单次响应限制为 8 MiB / 2 分钟；模型列表探测共享 32 请求、32 MiB / 1 分钟并拒绝重复 Gemini 分页标记；后台模型测试单响应限制为 16 MiB。
- KIE/APIMart 同步图片轮询共享 300 请求、32 MiB / 10 分钟；结构化生成响应限制 8 MiB、上传响应限制 512 KiB，MiMo TTS 响应限制 128 MiB。
- 持久化视频任务应在 360 次轮询、32 MiB 累计响应或自创建起 30 分钟任一预算耗尽时失败；重启后 `poll_count` / `response_bytes` 继续累计。Gemini 视频内容与通用 AI 媒体限制为 512 MiB。
- `/api` 的写请求按普通 JSON 2 MiB、同步数据 64 MiB、AI/画布任务 128 MiB、参考媒体 81 MiB、匿名上传 129 MiB 和登录用户对象存储上传 257 MiB 限制；KIE/APIMart 单参考文件超过 32 MiB 时明确失败而不是截断。
- 登录入口按 IP 限制 20 次/分钟、AI 生成按用户限制 60 次/分钟并发 4、上传和重型上游操作限制 30 次/分钟并发 2、下载限制 120 次/分钟并发 4；超限返回 HTTP 429 和 `Retry-After`。
