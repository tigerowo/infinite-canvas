## ComfyUI 通用可选媒体槽位

工作流：`【MINIMAX-H3】八月最强文戏-高配版.json`。六个图片槽位和三个音频槽位应在安全裁枝计划存在时默认为“关闭”；两个 `task_type` 字段应为 `auto`。

- [ ] 全部关闭：可进入 ComfyUI 队列，提交图中不存在 `217::image`。
- [ ] 仅开启后位图片：前面的图片槽位关闭时，启用图片仍进入其原始索引，不前移补位。
- [ ] 部分图片与音频：仅启用的槽位上传并连接，关闭分支被裁掉。
- [ ] 全部开启：六张图片与三段音频均按原始槽位提交。
- [ ] 刷新页面后重试：槽位模式保持不变，重试使用节点保存的模式。
- [ ] 陈旧计划：工作流结构变化后，Bridge 在入队前拒绝执行并提示重新拉取参数。
- [ ] 旧工作流回归：没有安全裁枝计划的 ComfyUI 工作流不显示可选槽位控件，提交行为不变。
