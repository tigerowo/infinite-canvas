# NewAPI 通道执行计划

目标：软件默认通过显式 `newapi` 协议访问网关；服务商协议仍可直连。模型名称不改变 NewAPI 请求路径，LEC 转换归 NewAPI 插件所有。

## 验收标准

- 新建渠道默认 NewAPI，旧渠道协议不迁移；本地/云端与协议、价格独立。
- 文本、图像、语音、视频走明确的兼容路径，后端不套用供应商适配器。
- 图像编辑传真实 multipart 文件；视频保留网关任务 ID，使用网关内容地址；提交失败不自动重发。
- 标准视频只发送已定义的字段；高级参考素材使用显式启用的版本化插件扩展，不支持的能力在提交前报错。
- LEC 专用 JSON 在 paipu 插件生成，客户端不含 LEC 模型判断。
- 完成本地契约测试、类型检查和 Go 测试，记录现存问题及未执行的真实上游验证。
- 完成后删除设计草稿，将边界、安装要求、变更路径、验证结果同步到正式记录。

## 范围及限制

NewAPI 参考源码固定为 `bee45b58a3c0b77e8dc81e6b5aeb4474aa9058d1`。插件 API 在参考文档中仍标为未发布，安装版本需要核实。当前只修改本地软件及本地插件，不部署、不推送、不发起付费生成。不同插件的模型能力不因统一 URL 自动相同；新增能力需明确协议版本及插件支持。
