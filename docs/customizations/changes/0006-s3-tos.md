# EXT-0006：修复火山引擎 TOS 上传失败

## 根因与范围

后端日志显示上传返回 HTTP 403、`InvalidPathAccess`。原 S3 实现固定以 `/bucket/key` 请求，但 TOS 只接受 `bucket.endpoint/key`。参见 [TOS 官方说明](https://www.volcengine.com/docs/6349/1288493?lang=zh)。前端第 265 行只是抛出后端统一返回的错误，并非故障源。

## 扩展与上游接入

`extensions/s3compat/endpoint.go` 根据 TOS 官方 S3 域名选择虚拟主机寻址，已带桶名前缀时不重复添加。其他服务保留路径寻址，签名使用最终请求中的同一转义路径。配置值及密钥不修改、不输出、不编入前端或测试。
