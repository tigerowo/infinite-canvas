# 素材统一通过 S3 公网 URL 传递

## 目标与边界

- EXT-0009；基线 `51c4503b2c53e237b2fe67c65711b51ae5deb762`；状态：实现中。
- 默认模型引用图片、视频和音频时，先将本地素材上传到 S3，再发送可匿名读取的 HTTPS URL。管理员可以在后台将图片切换为 Base64；视频和音频始终使用 URL。
- 管理员可以按模型 ID 覆盖文本、图片、视频、音频分类，用于修正上游模型列表的错误归类；这只影响前端选择和默认值，不伪造上游实际能力。
- 私有桶使用 24 小时 GET 签名链接，每次提交前刷新；签名 URL 不能永久使用，系统保存对象标识并在每次提交前重新签名。不修改桶 ACL、不公开密钥、不保存签名链接到数据库。
- 使用 AWS SDK v4 签名器，复用现有 TOS 寻址兼容。前后端实现集中于 `extensions/publicmedia/` 和 `web/src/extensions/public-media/`。

## 上游接入

管理后台的“模型与素材传输”面板通过 `/api/extensions/model-policy` 读取和保存策略。旧文件和生成结果仍使用原本的本地预览/持久化格式；仅模型输入按策略转换。不清理用户素材或生成历史。
