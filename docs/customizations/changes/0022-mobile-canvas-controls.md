# EXT-0022：移动端素材与摄像机控件优化

## 实际修改

- 素材选择器弹窗改为视口自适应宽度和高度，窄屏内容在弹窗内部滚动，避免固定高度裁切。
- 素材搜索框在手机端占满可用宽度，类型筛选标签支持换行。
- 素材卡片从手机端两列开始排列，较宽屏幕恢复四列，改善触控和标题可读性。
- 素材卡片增加封面加载失败占位，避免失效地址显示破图。
- 摄像机面板取消固定横向内容和缩放，手机端使用两列布局，桌面端保持四列。
- 摄像机面板根据触发按钮位置在上方或下方展开，并限制在视口左右边界内。
- 摄像机面板增加最大高度、Escape 关闭、焦点返回、对话框语义和标题关联。

## 验证

- TypeScript 检查通过。
- Next.js 生产构建通过。
- 首页 375px、1280px 无横向溢出，浏览器控制台错误为 0。
- 未登录访问 `/canvas` 按现有鉴权策略跳转登录页，375px 下无横向溢出。
- `git diff --check` 通过；仅有 Windows 换行符提示，无空白错误。

## 限制

- 当前浏览器会话未登录，素材选择器和摄像机面板的真实点击、定位和键盘操作尚未在登录后的画布页面完成人工操作验证。
