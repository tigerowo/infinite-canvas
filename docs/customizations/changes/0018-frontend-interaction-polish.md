# EXT-0018：前端交互与提示词库收口

## 目的

根据前端实际检查结果，修复提示词显示、触屏画布、底部工作台遮挡、侧栏搜索开销和失败状态反馈，使现有玻璃界面更适合继续联调和上线前验收。

## 实际修改

- 提示词卡片和详情弹窗对标签做前端去重；卡片摘要取消不必要的固定最小高度，保留约 120 字符和三行限制，避免短文本撑高卡片。
- 提示词筛选项在数据层去重，避免分类或标签重复渲染。
- 画布节点、调整尺寸手柄、连线点和全局拖动结束流程统一使用 Pointer Events；交互控件和画布专用面板不会误触发节点拖动。
- 图片和视频底部工作台使用 `ResizeObserver` 写入实际占用空间，结果区随参数面板展开动态预留底部空间。
- 画布提示词侧栏搜索增加 220ms 防抖并改用单次关键词查询；分类提示词只在用户展开分类时请求，避免输入关键词时并发加载全部分类。
- 图片和视频云端历史同步失败时继续显示本地记录，并提供重新同步按钮。
- 引用候选菜单补充 `listbox`、`option`、`aria-selected` 和当前候选项关联；只读提示词输入框补充默认可访问名称；移动导航和画布侧栏标签补充当前状态语义。
- 图片和视频工作台的 Enter 提交忽略输入法合成阶段，避免中文输入时误提交；生成提交和失败重试入口增加短时重复提交保护。

## 验证结果

- TypeScript：项目内 Node 执行 `tsc --noEmit` 通过。
- 浏览器：当前登录 Chrome 的提示词库页面可正常显示提示词摘要、标签和详情入口；摘要内容已截断且未把完整长提示词直接铺开。
- Next.js 生产构建：通过，20 个静态页面生成成功。
- `git diff --check`：通过；仓库仍会提示既有文件的 LF/CRLF 转换警告，没有发现空白错误。
- Bun 与 Go：当前 PowerShell 环境未提供可执行文件，因此没有重复声称相关测试通过。

## 限制

- 当前 Playwright 独立会话未登录，因此只能确认登录跳转；真实生成、媒体服务、OSS/CDN 和生产部署仍需在实际环境验收。
