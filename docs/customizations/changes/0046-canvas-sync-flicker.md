# EXT-0046 画布同步闪烁修复

## 问题与根因

账号画布同步每 5 秒检查一次。远端返回的媒体签名地址与本地可持久化快照不一致，导致 `remoteRevision` 在内容没有变化时持续递增，画布重复恢复节点，视频元素随之出现闪烁。

## 修改

- 同步远端项目、保存回执时统一使用可持久化媒体快照比较，忽略签名地址等运行时字段。
- 画布恢复时，若节点和项目状态没有实际变化，不再重复写入 React 状态；真实数据或签名地址变化仍可正常更新。
