# EXT-0021：提示词媒体容错与状态反馈

## 实际修改

- 新增可复用的 `PromptCoverImage`，统一处理空封面、加载失败和无效封面地址，显示稳定的占位状态。
- 提示词卡片、提示词详情弹窗和首页提示词展示改用统一封面组件，减少破图和空 `src` 对布局的影响。
- 提示词中心和提示词选择弹窗增加内联失败状态与“重新加载”按钮，避免请求失败时误显示为空结果。
- 首页提示词展示的标签继续去重，加载骨架和封面缩放动画支持 `prefers-reduced-motion`。
- 玻璃面板补充 `backdrop-filter` 不可用时的降级样式，并覆盖提示词头部、筛选区和卡片。

## 验证

- TypeScript 检查通过。
- Next.js 生产构建通过。
- `git diff --check` 通过；仅有 Windows 换行符提示，无空白错误。
- Playwright 首页 375px 检查无横向溢出，控制台错误为 0。
- Playwright 1280px 检查页面无横向溢出；未登录访问提示词库会按现有鉴权策略跳转登录页。

## 限制

- 当前浏览器会话未登录，提示词卡片的真实封面失败回退和详情交互未能在已登录页面完成运行时点击验证；代码已通过类型检查和生产构建。
