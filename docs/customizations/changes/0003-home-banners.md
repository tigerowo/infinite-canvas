# EXT-0003：移除首页商业广告轮播

## 目标与范围

上游基线：`51c4503b2c53e237b2fe67c65711b51ae5deb762`。状态：已实现，页面验证通过，完整类型检查存在上游既有错误。

用户要求删除 88API、Seedance 价格及 Metaso X MiniMaxH3 价格文案，并同意在无法保留原动画可靠去字时删除对应整张广告。广告文案嵌入 WebP 动画，采用整张广告排除方案：移除 `88.webp`、`metaso.webp` 两张广告素材，不修改或重新生成图片。

保留原有 `3ddirectortl.webp`、`agent.webp`（含视频）、`panorama.webp`、`3ddirector.webp` 四张功能展示图，以及轮播切换、拖动和视频预览行为。

## 扩展文件与上游接入

`web/src/extensions/home-banners/config.ts` 集中维护排除列表及过滤函数。无环境变量、CSS、图片副本、数据库或后端变化。

| 上游文件与符号 | 改动 | 必须修改的原因 | 同步检查点 |
| --- | --- | --- | --- |
| `web/src/app/(user)/page.tsx` / `HOME_BANNERS` | 导入过滤函数，初始化轮播数组时调用 | 上游轮播数据直接内联在页面，需在数据进入组件前接入过滤 | 保留上游新轮播数据；核对广告路径是否改名或附加查询参数，确认至少有一张可展示图片 |

上游轮播数组和轮播组件原样保留，过滤仅排除路径以 `/88.webp` 或 `/metaso.webp` 结尾的素材。上游更换命名时需重新审视排除列表，不声称能自动识别所有广告。

- 用户当前窄屏页面的 DOM 和截图确认仅有四个轮播指示点，顶部 GitHub 和登录入口保持隐藏；独立宽屏页面的导航及轮播也可用。
- 类型检查结果与本轮改动前的对照一致，只有 `canvas-client-page.tsx:4362` 的三条既有滑块类型错误（TS2322、两条 TS7031），无新增诊断；未执行生产构建。
- 上游 TODO 和待测试文档已检查，无需重复记录本项定制。
