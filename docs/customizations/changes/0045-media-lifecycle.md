## 已确定的行为

默认 30 天，素材有效使用和业务编辑续期；一直保存也登记活动。仅观察清理候选为默认值，真实清理需管理员启用。立即清空是独立操作，必须预览并确认批次范围。

登录后粘贴分享 ID 只建立草稿引用，不自动收藏。原作者删除后旧分享 ID 停用，其他用户已取得的引用保留。图片、视频、音频参考合计最多 50 个。容量只统计，不新增收费或硬额度。

保留账号、权限、余额、必要结算状态、系统与账号配置、系统预设 Skill 和公共提示词；用户业务和管理员素材库按规则清理。OSS 清理仅覆盖明确的应用管理范围，不处理其他应用或 Python 临时平台。

任务保护上限 24 小时；归档自动重试最多 12 次、最长 6 小时且受总期限约束，退避最多 15 分钟。不重新提交付费生成。缺失可靠活动记录的旧数据获得完整迁移窗口。

## 已确认缺陷与修复

| 场景 | 根因/分类 | 最小修改与证据 |
| --- | --- | --- |
| 删除超时后旧执行器返回、两个批次删同文件 | 应用缺陷：批次锁不能覆盖跨批次文件 | 文件与批次独立租约；失租不能确认删除或清掉定位；`cleanup_recovery_test.go` |
| 预览同毫秒内新增数据漏检 | 应用缺陷：只比较时间 | 比较实体/文件身份与版本；清空前核对在途上传、请求和执行器；完成前检查旧 epoch 剩余数据 |
| 修改 endpoint/prefix 后沿旧对象删除 | 应用缺陷：scope 缺原始范围信息 | scope 补齐，预检及每次删除核查；legacy 无法证明原地址时明确拒删，等待可靠迁移 |
| 长上传失租、PUT 成功但索引失败 | 应用缺陷：对象与数据库非原子 | PUT 前登记定位、每分钟续租、失租取消、只恢复元数据；直传登记和引用原子写入 |
| 坏结果阻塞所有任务、旧轮询覆盖新任务 | 应用缺陷：恢复未逐项隔离、缺租约验证 | 独立恢复并汇总错误；坏 JSON 保留 unknown；进度/结果验证 worker、epoch、期限和恢复版本 |
| 跨账号同历史 ID 覆盖，删除后换 ID 复活 | 应用缺陷：全局主键和别名删除不一致 | 历史/任务/输出别名、墓碑、业务行、引用同事务；查询故障不能当作不存在；`history_test.go` |
| 旧历史迁移覆盖账号模型/存储设置 | 应用缺陷：整行写回旧配置快照 | 原 JSON 字段 CAS，迁移与清空字段同事务；坏 JSON 原样保留并报错 |
| 手动归档恢复后旧响应、刷新把状态退回失败 | 应用缺陷：版本漏传和载入丢字段，拒绝保存后仍使用旧 log | receipt 固定原版本、旧快照不能借新版本；规范化保留版本，卡片/保存/归档只用已接受状态 |
| 连续点重试重复安排或延长保留期 | 应用缺陷：重试沿用普通续期 | 等待中的恢复拒绝重复安排；仅推进恢复版本，不改活动/保护期限；`tasks_test.go` |
| 历史刷新/新增/删除交叉与磁盘乱序 | 应用缺陷：并行写入和旧整表快照 | 图片/视频共用串行写队列及快照合并；页面实际函数的延迟 IO 测试覆盖旧响应/删除/账号变化 |
| 本地历史跨账号或清空后混入旧数据 | 应用缺陷：IndexedDB 未隔离 | 按账号和 epoch 读写/清除；旧无归属历史保留磁盘不自动上传；`history-store.test.ts` |
| 缩短期限不用确认影响 | 功能缺口 | 策略预览 receipt 有效 15 分钟，绑定规则与候选；变化须重预览，观察模式不执行删除 |
| PostgreSQL upsert 的 version 歧义 | 数据库兼容缺陷 | 使用表限定列；实际 PostgreSQL 测试通过 |
| “我的素材”整列表覆盖、并发删除复活 | 应用缺陷：没有服务端版本和本机 scope | `asset-sync.ts` 三方合并；删除优先；同字段冲突提示；按账号/epoch 存储；新增 8 项回归测试 |
| 旧客户端或旧 epoch 的素材响应回写 | 应用缺陷：响应未核对账号、代次和加载代号 | `use-asset-store.ts` 在读、写、解析媒体后核对 session；同步失败显示本机保留；隔离镜像真实 UI 回归 |
| AI 日志绕过统一期限、Windows 文件重写失败 | 应用缺陷：独立按天清理入口与生命周期并存，数据库和 JSONL 没有一致性租约，`os.Rename` 依赖 Unix 覆盖语义 | 移除独立清理路由/Cron 控件；写入和旧日志同步使用 request lease 与 epoch；原始 `CreatedAt` 决定期限；文件采用可恢复备份替换；finalizer 持续续租；`ai_log_lifecycle_test.go`、`cleanup_recovery_test.go` |
| MySQL 8.4 Error 1170：object_key TEXT 索引未指定长度 | 现有上游迁移缺陷，仍阻断 | 尚未改字段或测试夹具，不能宣称三库通过；需完成最小兼容方案及风险说明 |
