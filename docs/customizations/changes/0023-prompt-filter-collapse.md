# EXT-0023：提示词标签筛选收起展开

## 实际修改

- 提示词中心的标签筛选超过 9 项时默认收起，初始显示前 8 项和当前已选标签。
- 增加“展开全部标签”和“收起标签”按钮，显示隐藏标签数量，避免筛选区域占据过多页面空间。
- 画布内提示词选择弹窗同步使用相同的收起展开规则，保持两个入口的交互一致。
- 收起按钮补充 `aria-expanded`、`aria-controls` 和可见焦点样式，支持键盘操作。
- 展开状态不改变已选筛选条件，也不修改提示词接口和分页逻辑。

## 验证

- TypeScript 检查通过。
- Next.js 生产构建通过。
- 首页 375px、1280px 无横向溢出，浏览器控制台错误为 0。
- 未登录访问提示词中心按现有鉴权策略跳转登录页；登录后的标签数量和展开交互待在真实账号会话中人工检查。
- `git diff --check` 通过；仅有 Windows 换行符提示，无空白错误。
