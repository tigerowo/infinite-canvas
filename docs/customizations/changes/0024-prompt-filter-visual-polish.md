# EXT-0024：提示词筛选视觉收口

## 实际修改

- 将提示词中心和画布内提示词选择弹窗的 Ant Design `CheckableTag` 改为统一的原生筛选胶囊按钮。
- “全部”、分类、普通标签和展开操作统一尺寸、圆角、边框和激活态，消除激活项方块化和文字散落感。
- 展开操作改为同一筛选系统内的虚线次级按钮，继续保留隐藏数量和已选标签。
- 提示词中心头部与筛选区统一最大宽度，缩小标题区留白并调整移动端标题字号。
- 模型选择下拉收窄到视口友好的尺寸，无模型时使用更短的状态文案。
