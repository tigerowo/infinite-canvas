> 后续 [EXT-0011](0011-newapi-channel.md) 为显式 NewAPI 通道补充未登录直连下载及软件任务 ID 到网关任务 ID 的后台映射。下面记录本项初版范围。

## 标识与目标

- EXT-0010；基线 `51c4503b2c53e237b2fe67c65711b51ae5deb762`；状态：已实现，用户反馈当前使用流程可用，完整验证范围见下文。
- 触发条件：账号代理视频任务已完成，但没有返回 `video_url` 或 `url`，且尚未有 `storageKey`。此时从 `/videos/{id}/content` 读取实际视频，再缓存用于显示。
- 这是结果文件获取的兼容修复，与 EXT-0008 的提交请求体、EXT-0009 的参考素材输入处理分别作用于不同阶段；不修改 NewAPI 服务端。

## 行为与限制

- 普通无 URL 的新增回退受 `usesAccountProxy(config)` 限制，不表示所有未登录直连渠道都自动支持内容接口；已有 88API、Grok 条件保留。
- 非成功 HTTP 状态报下载错误；JSON 或文本响应报内容错误，不当成 MP4 保存。其余响应交给现有 `uploadMediaBlob`，该检查不是完整的视频解码校验。
- 缓存沿用原文件存储策略，文件名为 `generated-<任务ID>.mp4`，不保证所有环境都上传到 S3。接口返回已有可用 URL 时，沿用原行为。
