## 已确认的方向

1. 首页聊天与画布侧栏默认用于文本对话，保留 Agent 根据对话调用图片、视频工具的能力。
2. 文本模型选择移到输入框底栏；图片、视频参数不再常驻底栏，收进按需展开的工具设置，继续作为 Agent 的生成默认值。
3. 将普通 API 的推理开关改为思考强度选择，选项按渠道协议和模型实际支持能力显示。
4. 全站统一中性黑灰色系，覆盖首页、画布、生图和视频的底部/侧边工作台、素材页、弹窗、下拉和后台；画布默认使用淡点阵，图片节点保留淡边框，选中时高亮。
5. 对象存储只提供火山 TOS、七牛云的常用配置入口，两家都能配置，明确选择一家作为默认上传位置。
6. CDN 只提供腾讯 EdgeOne、阿里 ESA 的配置入口，同时保留不使用 CDN 的签名直读方式。
7. 图片、视频生成成功后自动保存到当前默认存储；保存失败时保留结果并提示重试，重试只重做保存，不重新生成。
8. 交付软件发往 NewAPI 的独立接口文档：逐项写明文本、图片、视频、音频的 HTTP 端点、参数类型、发送条件、素材形式和返回要求，方便后续编写 NewAPI 上游适配器或插件。
9. 补充主动排查逻辑、UI 和性能问题，记录依据、优先级与验证方式；已根据“开始修复吧”进入实现，未复现线索不写成已修复。

## 修复前核查

### 对话和思考强度

- 首页与画布共用 `CanvasAssistantComposer`；首页先创建画布并传递待执行消息，实际执行发生在画布。
- `canvas-assistant-composer.tsx:94` 把文本模型单独放一行；`:123` 和 `:134` 无条件渲染图片、视频参数。
- `canvas-assistant-composer.tsx:147` 目前是布尔开关，不是下拉菜单。因此已确认“强度选择未实现”，尚未在浏览器复现“点击开关本身完全无效”。
- `web/src/services/api/canvas-agent.ts:101` 的 `applyCanvasAgentReasoning` 在多条普通 API 分支固定发送 high；Gemini 2.5 使用自动预算，MiMo 使用启用开关。关闭仅省略推理字段，并不保证模型停止思考。
- Codex 模式已有独立能力选项，不应把其完整强度列表直接套到普通 API。
- Agent 工具参数仍影响实际生成；`autoGenerateMedia` 也影响是否直接提交生成。收起控件不能清空这些配置，后续实现需核对首页创建项目、画布设置与 Agent 执行策略的一致性。

### 画布、弹层和后台

- `web/src/lib/canvas-theme.ts:41` 的深色画布为 `#181715`，与首页 `bg-background` 不是同一个颜色来源。
- `canvas-node.tsx:140` 将未选中且非关联图片节点边框设为透明。
- `canvas-node-prompt-panel.tsx:92` 的工具栏可换行，但模型、参数和相机多项固定宽且禁止缩小；生成按钮高度为 44px，其他控件存在 32px、40px，容易产生不齐和单独换行。
- `model-picker.tsx` 使用 Radix Select；节点输入面板拦截 pointerdown/mousedown 冒泡，Radix 外部点击关闭依赖 document 冒泡事件。这是菜单不收起的代码依据，具体首次点击失效路径仍需浏览器复现。
- 后台渠道表格固定列合计 596px，尚不含名称和模型；未配置表格自己的横向滚动。浏览器当前后台页面已观察到横向滚动条，但尚未逐一排除其他表格的贡献。

### 素材上传和模型传输

当前流程依调用入口和接口契约不同，不能概括为所有素材都经过 OSS 后只传链接。

| 场景 | 当前行为 |
| --- | --- |
| 普通图片上传 | 优先尝试云存储；localOnly 或不可用时可保存在浏览器 |
| 部分视频、音频上传入口 | 先保存在浏览器 localforage，供后续处理 |
| 通用模型 URL 参考素材 | 必要时上传应用后端，再由后端写对象存储；已有 server 对象复用，另申请模型读取签名 URL |
| 通用图片 Base64 策略 | 转成 Data URL，不执行该转换函数后续的 OSS 上传步骤 |
| NewAPI Images 编辑 | 按接口契约提交 multipart 图片文件 |
| NewAPI Chat / Responses 图片输入 | 当前适配器提交 Data URL |
| NewAPI 标准视频 | 单张参考图以 input_reference 文件提交；不能直接替换成 URL |
| NewAPI canvas-v1 视频扩展 | 通过扩展媒体字段传 URL 或对应图片策略生成的 Data URL |

模型读取 URL 当前由 `extensions/publicmedia/urls.go:17` 签发，约 24 小时有效，指向 S3 源站；用户预览由 `service/storage.go:186` 签发，约 5 分钟有效，可使用已配置的 EdgeOne。二者不可混为永久公网链接，也不可把预览的短链接直接持久化为素材地址。

“文件已经进入我的存储”和“模型接口接收文件还是链接”是不同问题。界面应让用户上传一次，系统复用存储对象并自动按模型协议转换，无需用户复制公网链接再上传。

生成结果目前未统一归档：部分后台任务保存模型返回 URL，前端存在手动上传云端操作，受保护视频内容有单独回存路径。不能把现状写成所有生成结果已经自动进入 OSS。

### 存储与 CDN

- TOS、七牛已有 S3 地址适配；当前后台仍提供通用 S3/R2、WebDAV、权重等配置。
- `extensions/storageaccess/config.go:77` 只支持 s3、edgeone-b，ESA 尚无对应签名实现。
- 当前 CORS 功能保存来源并生成规则，需要在存储或 CDN 控制台应用；在本应用点击保存不会自动配置厂商端。
- 已有素材依赖的 Provider 不能直接删除或改指向。切换默认上传位置应只影响后续上传，历史素材继续从原 Provider 读取。

## 推荐交互方案

### 对话底栏

输入区保持在上，附件预览紧邻输入内容；底栏按“添加素材 / 工具设置、文本模型、思考强度、发送或停止”排列。Skill 与图片/视频默认模型和参数收进工具设置，不再单独堆一排常驻参数。

思考强度默认显示“自动”，含义为不强制指定，使用模型或渠道默认。只有经协议和模型能力确认支持时才显示其他档位；支持关闭的模型才提供关闭。切换模型时重新校验档位，不把前一个模型的无效参数发给新模型。历史布尔配置需要兼容，不能仅修改按钮外观。

保留 Agent 自动调用媒体工具的能力。生成前应能看到使用的图片或视频模型及关键参数；模型未配置时指出缺少的具体设置。纯文本消息不得因为隐藏的媒体模型尚未配置而无法发送。

### 画布和节点

统一全站中性色基底，重点覆盖生图、视频创作台下方输入区；不能只改首页与画布。全局玻璃变量与页面硬编码 stone 色需要共同核对，完整范围见[排查报告](ux-logic-performance-audit.md)。保留功能状态色，不改素材颜色。画布不复制首页装饰光晕，避免影响辨认图片。淡点阵为新画布默认，现有用户明确选择的背景模式保留。

图片节点默认边界可见，选中高亮，缩放后仍能辨认。生成工具栏建议桌面可见控件统一为 36px 高；模型名称可缩略、模型选择控件允许收缩，发送固定在末端。窄屏必要时将参数整体放到第二行，避免只剩发送按钮单独一行。触屏区域保留足够点击面积，不用极小按钮解决溢出。

全站配色的验收范围如下。共享中性色已接入，浏览器已检查首页、画布、图片/视频工作台和后台；其他组合仍需人工验收，同时保留错误、警告、成功和选中状态色。

| 区域 | 必须覆盖的表面与状态 | 验收重点 |
| --- | --- | --- |
| 全局主题 | 普通/强调玻璃表面、边框、遮罩、悬停态 | 中性黑灰基底一致，深浅色切换仍可读 |
| 首页与画布 | 页面、侧栏、输入区、节点、工具栏、弹层、点阵 | 进入画布不突然变暖灰，图片边框在不同缩放下可辨认 |
| 生图工作台 | 底部布局和侧边布局、输入框、模型下拉、提交区 | 用户指出的下方工作台与页面背景协调，不能只改外层 |
| 视频工作台 | 底部布局和侧边布局、输入框、模型下拉、提交区 | 与生图使用同一套中性表面，各状态无残留暖棕 |
| 图片/视频结果与历史 | 页面、结果卡片、空态、加载、详情 | 历史区与工作台一致，不改变素材本身色彩 |
| 我的素材与素材库 | 搜索、筛选、卡片、预览和编辑弹窗 | 上传、预览、编辑状态衔接一致 |
| 公共弹窗与移动导航 | 应用设置、提示词详情、封面、导航抽屉 | 浮层、下拉与移动端没有独立偏色背景 |
| 工作流及视频附加面板 | 工作流工作区、Kling 附加工作台 | 复用共享表面，保留功能性颜色 |
| 后台及其他页面 | 设置、AI 日志、版本弹窗、404 | 表格和弹窗不溢出，主题一致 |

配色修复按实际页面截图与交互状态验收，不以搜不到某个颜色字符串作为唯一完成条件。本轮保留原有玻璃透明程度。

### 存储卡片

常用入口展示 TOS 与七牛两家服务商的连接卡片；已有多连接或其他 Provider 配置兼容保留，不强制迁移或删除历史素材依赖的配置。

| 区域 | 常用内容 |
| --- | --- |
| 卡片摘要 | 名称、服务商、启用状态、是否默认上传、已验证状态 |
| 连接 | 区域、存储桶、访问密钥；Endpoint 使用厂商正确地址，支持检查或高级覆盖 |
| 文件访问 | 直接签名访问 / EdgeOne / ESA；选择 CDN 后才出现域名和必要鉴权配置 |
| 跨域 | 画布站点来源；一键加入当前站点；对应厂商规则与操作说明 |
| 高级 | 路径前缀、容量限制和统计等低频项 |

默认上传需成为显式策略，不能只是把现有权重字段改名；同一时刻只有一个默认目标。默认目标不可用时，应显示失败原因并允许重试；是否自动切换另一家不作为默认行为。切换默认不迁移既有对象。

CDN 按存储连接独立选择，不固定 TOS 必须搭配哪家 CDN。不使用 CDN 也应可以完成上传、预览和模型参考读取。

检查入口区分连接、浏览器跨域、签名读取、CDN 回源和视频 Range。保存成功仅代表配置保存，不能代表这些检查通过。测试应使用受控的小型样例，不能默认发起付费模型生成。

ESA 需要独立核对当前产品的访客鉴权、私有 S3 回源和缓存规则；不能仅换域名或照搬 EdgeOne Type B。两种 CDN 与两家存储的实际组合需分别标注验证结果。

### 后台配置组织

建议按“模型渠道、存储与访问、其他设置”分组，让渠道连接、模型拉取与分类靠近。长模型清单收成数量与查看入口；桌面操作列保持可达，手机用摘要卡片或适当隐藏低频字段。公开/私有字段的后端访问边界保持不变，界面分组不等于改变密钥权限。

## 补充建议和待确认项

- 已确认图片和视频生成结果自动归档到默认存储，区分“生成成功”“保存中”“已保存”“保存失败，可重试”。保存失败时保留可用结果和原始来源；临时源链接仍可能过期，不能把失败状态标为已永久保存。音频自动归档不在本轮已确认范围。
- 建议错误提示区分模型请求失败、上传失败、签名过期、浏览器跨域失败；截图中的 Failed to fetch 需要单独复现，当前不能认定由 CORS 或思考参数导致。
- 建议费用未知时显示“费用待确认”或省略数字，不把缺失估算展示成免费；实施前核对现有费用计算和渠道模式。
- 普通 API 强度由集中能力表校验；ESA 使用独立 Type A 签名；归档恢复和去重的实际边界见 EXT-0031。
- 生图高级参数进一步折叠、后台整体分组仍保留为建议，本轮保持现有组织和玻璃透明程度。

## NewAPI 接口文档与补充排查

[软件发往 NewAPI 的接口文档](newapi-interface-contract.md)以 NewAPI 收到的请求为主线：文本 Chat / Responses 的消息与工具参数，图片三种模式的字段与参考图格式，视频标准 JSON / 文件请求及 Canvas v1 扩展，语音合成的 input、voice、speed 等参数。每条路径写明端点、字段类型、发送条件、示例和软件要求的返回结构，供后续接上游、编写插件时查阅。具体供应商限制和插件宿主 SDK 不混入软件请求定义；思考档位等行为变更实施后再同步接口文档。

[界面、逻辑与性能排查](ux-logic-performance-audit.md)保留源码依据和验证限制；下面将其 12 项问题全部纳入待修清单。P1 优先保护任务正确性、素材恢复和账号边界；P2 处理可靠性、交互与性能。静态确认不等于线上影响已复现，执行时按下列触发条件验证。

### 原始补充问题与验收目标

| 编号 / 优先级 | 问题与修复目标 | 验收条件 | 状态 |

| AUD-01 / P1 | 视频创建使用用户云端 Key，后台查询可能改用管理员 Key；创建、轮询、内容下载按同一任务所有者和渠道身份选取凭证 | 两套隔离 Key 下创建到下载全流程正常；恢复后台任务仍用正确身份；密钥不进入任务公开数据或日志 | 待修复，选路差异已静态确认，线上影响待验证 |
| AUD-02 / P1 | Responses 生图只有 partial 预览也可能报成功；区分预览、最终完成、失败和中断 | 仅 partial 后断流不标成功；失败终态保留预览但明确未完成；正常终态才保存最终结果 | 待修复，回退行为已确认 |
| AUD-03 / P1 | 浏览器私有媒体 Blob 缓存未按账号隔离；按账号分区或校验缓存所有者，退出时释放内存引用 | 同一浏览器 A 退出后 B 不复用 A 的私有缓存；签名与 Blob 两层身份一致；用隔离账号复现，不把此项当作已证实的服务端越权 | 待修复，界面跨账号触达路径待验证 |

| AUD-06 / P2 | 图片同步失败静默停用后续同步，视频失败也被吞掉；保留未同步状态、待传记录和重试入口 | 断网时提示未同步；恢复后补传且不重复；失败不会无提示地永久停止同步 | 待修复 |

### 原始核查与文档目标

这些项目也纳入工作范围，但尚不足以认定为具体业务缺陷，先验证再决定修改：

| 编号 | 项目 | 目标与验证方式 | 状态 |
| --- | --- | --- | --- |
| CHK-01 | Failed to fetch 提示不便定位 | 复现网络、上传、签名、跨域、模型请求错误，按实际失败阶段给出可操作提示；不把所有错误归因于 CORS | 待复现与改进 |
| CHK-02 | 生成按钮显示 0 容易误认为免费 | 核对估算、额度、渠道模式和未配置价格的语义；仅未知费用时改为待确认或不显示，保留确实免费的情况 | 待核查 |
| CHK-03 | 大画布和长列表性能 | 使用固定规模数据测拖动帧耗时、历史滚动、签名请求量、后台表格和视频资源占用；记录环境与指标，只有发现瓶颈才实施针对性优化 | 待测量，不预设重构方案 |
| DOC-01 | 软件到 NewAPI 接口说明不聚焦 | 独立文档以网关收到的端点、参数、文件和响应为主；与当前代码核对，后续请求变更同步更新 | 文档已重写，在线联调未执行 |
| DOC-02 | 旧架构描述称全部前端直连 | 后续同步描述账号代理及本地直连各自适用范围；相关项目规则需专项修订，不能据旧描述判断真实请求 | 待文档修正，本轮未改项目规则 |

### 建议实施顺序

1. 先处理 AUD-01 至 AUD-04，建立身份、最终结果与素材恢复的可靠基础。
2. 处理用户标注的输入栏、模型菜单、节点边框、按钮对齐、表格溢出，以及上列全站主题范围；同时修正 AUD-11 的无效参数展示。
3. 简化 TOS/七牛与 EdgeOne/ESA 配置，落实显式默认上传和自动归档；结合 AUD-05、AUD-08、AUD-12 统一读取重试及保存状态。
4. 处理 AUD-06、AUD-07、AUD-09 的同步、删除与缓存生命周期，再按 AUD-10、CHK-03 的测量结果优化性能。
5. 更新接口及架构说明，完成下列验收。各项可独立交付，不把“全部主题已换色”当作逻辑缺陷已解决。

## 实施范围与验收

按“对话交互、全站视觉与弹层、任务与账号边界、存储与归档、同步与性能”拆分独立修改记录。新业务集中在前后端扩展目录；共用组件、画布状态和 Provider 选择处只保留必要接入。正式实现时按单项模板登记编号，并逐项更新本清单状态，不把修复方案登记成已实施修改。

1. 标注 1–12 全部有对应回归操作；以用户提供的 687×559、1038×912 视口复现，并补充手机与宽屏。
2. 首页发送后进入画布，文本模型、思考强度、媒体工具默认值正确延续；纯文本及 Agent 图片/视频工具路径分别检查。
3. 各强度选择的请求载荷符合实际模型协议；自动省略强制值，不支持的档位不可选择；Codex 原有强度路径不退化。
4. 下拉首次外部点击、输入聚焦、Escape、选项选择与画布拖动互不干扰。
5. 全站与生图/视频两种工作台布局颜色衔接一致；浅色/深色、点阵、图片边框、不同缩放、小窗口、下拉和弹窗可用。
6. 默认存储切换只影响新上传；旧素材仍可访问；凭证和临时签名不写入公开配置、项目 JSON 或日志。
7. TOS、七牛分别检查上传、读取、中文对象名、签名过期和越权访问；模型文件/Data URL/签名 URL 契约分别检查。
8. EdgeOne、ESA 分别验证浏览器 CORS、私有回源、访客鉴权、缓存和视频 Range；未连接真实云端的组合标记未验证。
9. 后台长名称、大量模型和窄屏不撑宽整页；保存、编辑、测试操作始终可达。
10. 自动归档需验证生成成功但归档失败、重试不重复生成或重复创建对象、页面重载与历史素材读取；保留可用结果不等于保证未归档的临时链接永久有效。
11. 四类 NewAPI 接口文档随实现同步，通过本地请求契约测试核对示例和真实序列化；网关与供应商在线能力另行验证。
12. 排查报告中的 P1 先完成隔离复现与修复验证；性能项对照固定数据规模记录前后指标，不以主观“更快”作为验收。

当前已实施代码修复、Go/Bun 测试、TypeScript 检查、生产构建及隔离 Playwright 交互检查。没有请求真实付费模型、上传/删除真实云对象或修改厂商控制台。性能指标没有测量结果，不宣称优化倍数。
