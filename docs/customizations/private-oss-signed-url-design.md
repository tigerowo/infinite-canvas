# 私有 OSS 临时签名访问设计

## 目标

全局云存储允许配置多个 S3/OSS Provider，但至少要有一个启用且配置完整的 OSS；图片、视频和音频由浏览器直接下载，微鑫画布只负责登录校验、对象归属校验和签发短时 GET 能力。文件正文不经过微鑫画布服务器。

## 访问链路

```text
浏览器 --对象 ID、登录凭证--> 微鑫画布后端
浏览器 <--短时签名 URL---- 微鑫画布后端
浏览器 ------------------> 私有 OSS S3 Endpoint（直接读取）
```

签名 URL 是短时 bearer capability，默认 5 分钟；拿到 URL 的人可在有效期内读取对应对象，因此不能写入项目数据、localforage 或日志，也不能声称它可以被即时撤销。

## 后端规则

- 路由为 `GET /api/v1/files/{id}/signed-url`，必须经过现有用户鉴权。
- 后端只使用数据库中的对象 ID、Provider、Bucket 和 ObjectKey，不接受客户端提交的路径或密钥。
- 普通用户只能读取自己创建的对象，管理员可按现有管理员权限读取。
- 只为配置完整的 S3 Provider 签名；WebDAV、本地缓存和公开旧 URL 继续使用原路径。
- 私有对象的旧内容接口不能保持匿名可读。签名失败时只能在已鉴权且完成归属校验的上下文中回退代理，避免用旧接口绕过私有权限。
- 不改变 `publicBaseUrl` 的公开 URL 语义。它不能被自动当作任意 CDN 签名域名；CDN 需要单独实现与供应商匹配的签名和回源配置。

## 前端规则

- 项目数据仍只保存 `server:<objectID>`，不保存临时 URL。
- 签名 URL 只保存在内存，按对象 ID 和当前登录用户隔离，并在过期前预留安全余量。
- 图片、视频、音频、下载和参考素材读取统一优先签名 URL；签名接口失败时使用经过权限校验的后端回退。
- OSS 请求不携带微鑫画布的 Authorization；视频继续交给浏览器发起 Range 请求。
- 收到签名过期类 401/403 时清除内存缓存并最多重新申请一次。

## 存储与部署要求

- Bucket 保持私有，不开启匿名读。
- OSS CORS 只允许实际站点来源，并允许 GET、HEAD 及视频所需响应头。
- S3 Endpoint 必须是后端可访问、且与 Provider 区域和签名规则匹配的 API Endpoint。
- 是否使用 CDN 另行配置；只有完成 CDN 的签名透传、回源和缓存规则后，才把 CDN 地址接入签名器。

## 数据库边界

继续复用现有 `StorageObject` 和存储 Provider 配置；私有 CDN/CORS 的每个 Provider 配置保存在扩展表 `ext_storage_access`，通过 Provider ID 和 Endpoint/Bucket 快照隔离。普通设置仍保存在 `settings`，不修改 NewAPI 数据库。数据库保存索引和访问配置，OSS 保存文件本体。

EdgeOne 接入使用 Type B URL：`/{YYYYMMDDHHmm}/{md5}/{objectKey}`，签名计算为 `MD5(密钥 + 时间戳 + /objectKey)`。EdgeOne 验证通过后剥离前缀再回源，因此必须在 EdgeOne 为素材域名配置私有 S3 兼容回源；只有完成外部配置后才能启用该模式。

## 验收标准

1. 未登录和越权用户不能获得签名 URL，也不能用旧内容接口读取私有对象。
2. 合法用户获得的 URL 只允许 GET、只对应数据库对象、有效期不超过 5 分钟。
3. 浏览器读取私有对象时正文请求的目标是 OSS；视频 Range 播放可用。
4. URL 过期后最多自动刷新一次；本地缓存、WebDAV 和旧公开对象继续可用。
5. 不出现密钥、签名 URL 或数据库密码进入前端持久化和日志。
