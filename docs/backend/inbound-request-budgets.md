# 入站请求读取预算

后端在 `/api` 入口按路由类型限制 POST、PUT 和 PATCH 请求体。已知 `Content-Length` 超限时立即返回 HTTP 413；分块传输或未知长度请求通过 `http.MaxBytesReader` 在读取阶段停止。

| 请求类型 | 总请求体上限 | 额外限制 |
| --- | ---: | --- |
| 普通认证、配置、管理和工作流 JSON | 2 MiB | Provider 接口继续使用更严格的 256 KiB；本地直连转译为 1 MiB |
| 画布项目、用户数据和生成历史同步 | 64 MiB | 覆盖项目/历史批量同步 JSON |
| AI 生图、文本、语音、视频及画布异步任务 | 128 MiB | 与 AI 代理原生请求上限一致 |
| 匿名对象存储上传 | 129 MiB | 保留 multipart 边界和字段开销 |
| 参考媒体上传 | 81 MiB | 图片 30 MiB、视频 50 MiB、音频 15 MiB；按媒体类型只落盘到上限加 1 字节 |
| 登录用户对象存储上传 | 257 MiB | 文件内容 256 MiB，额外 1 MiB 用于 multipart 元数据 |
| KIE / APIMart 单个参考文件 | 32 MiB | 使用 `limit + 1` 检测，超限明确失败，不再静默截断 |

## 执行规则

- 路由入口限制总请求体，具体处理器可继续施加更严格上限。
- multipart 临时文件在请求结束后调用 `RemoveAll` 清理。
- 对象存储上传在进入 `[]byte` 和服务层前检查文件内容上限，避免无界内存分配。
- 画布任务包装体在解析 JSON 或 multipart 前限制为 128 MiB。
- 参考媒体先根据类型确定上限，超过上限时停止继续写入并删除不完整文件。
- 本文只描述客户端到 Infinite Canvas 的入站请求；第三方上游响应限制见[上游读取预算](upstream-read-budgets.md)。
