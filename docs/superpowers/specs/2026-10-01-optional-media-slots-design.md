# ComfyUI 通用可选媒体槽位设计

## 背景

Infinite Canvas 当前会把 ComfyUI 工作流中的 `LoadImage`、`LoadVideo` 和 `LoadAudio` 自动映射为画布参考素材。字段映射支持素材顺序和“缺失时阻止生成”，Bridge 也会在映射素材缺失时删除直接加载节点及其第一层连接。

这套行为不足以表达 ComfyUI 前端插件提供的“启用/忽略一组参考素材”能力：

- GoohaTOOLS 等前端分组开关不会进入可执行 API JSON，Bridge 无法读取其开关状态。
- 自动发现会把第一个图片、视频或音频槽位标记为必填，零参考素材请求会在服务端被拒绝。
- 当前 Bridge 只删除加载节点和第一层连接；加载节点后存在缩放、预览等中间节点时，残留节点仍会因缺少必填输入而使 ComfyUI 校验失败。
- 参考素材数组无法同时表达“关闭槽位”“使用工作流默认素材”和“使用画布素材”三种状态。

目标是增加与具体 ComfyUI 插件无关的通用可选媒体槽位，使同一工作流能够在零素材、部分素材和全部素材之间安全切换。

## 目标

- 工作流检查时识别能够安全断开的图片、视频和音频分支。
- 工作流配置允许将安全分支声明为可选媒体槽位。
- 画布生成节点按槽位显示开关，并支持三种运行模式：关闭、画布素材、工作流默认素材。
- 关闭槽位时，在提交给 ComfyUI 前删除完整的专属媒体分支，并在可选输入边界断开连接。
- 关闭全部槽位时仍可运行支持文本生成的融合模型工作流。
- 保持现有工作流行为不变；未声明为可选的媒体字段继续按原规则校验。

## 非目标

- 不复刻 GoohaTOOLS 的分组界面或读取其私有状态格式。
- 不允许任意节点被用户强制删除；只有 Bridge 验证过的安全裁剪计划可以启用可选槽位。
- 不自动推断所有模型的任务模式。工作流中的 `task_type` 等业务字段仍由字段配置设置；当前 MiniMax H3 工作流配置为 `auto`。
- 不改变 RunningHub 工作流行为。本次只作用于本地 ComfyUI Bridge。

## 用户体验

### 工作流配置

字段配置新增“可选媒体槽位”状态。Bridge 能够生成安全裁剪计划时，图片、视频或音频字段可配置为可选；无法安全裁剪时显示原因并保持普通必填/默认字段。

每个可选槽位包含：

- 显示名称和媒体类型。
- 图片或音视频槽位序号。
- 默认运行模式：`off`、`canvas` 或 `default`。
- 自动生成的只读裁剪摘要，用于说明关闭后会删除哪些节点并在哪些输入处断开。

### 画布生成节点

生成节点的参考内容区域按类型汇总为“参考图片 n/m”“参考视频 n/m”“参考音频 n/m”。展开后，每个槽位显示：

- 开关。
- 模式：画布素材或工作流默认素材。
- 绑定到该槽位的上游素材摘要。

“全部启用”和“全部关闭”只修改可选槽位。关闭全部参考槽位时显示“无参考素材”，生成按钮仍可用。

画布素材按照已启用且模式为 `canvas` 的槽位顺序绑定。关闭前面的槽位不会让后续槽位错位；前端构造稀疏素材数组，保留真实槽位下标。

## 数据模型

### 工作流字段配置

`WorkflowFieldMapping` 增加以下字段：

```text
optionalMedia: boolean
mediaDefaultMode: "off" | "canvas" | "default"
mediaPrunePlan?: {
  removeNodeIds: string[]
  detachInputs: Array<{ nodeId: string; fieldName: string }>
}
```

`mediaPrunePlan` 由 Bridge 检查工作流时生成，前端只读。服务端保存时保留该结构，但不自行构造或扩展。

### 单次运行状态

`WorkflowRunInput` 增加：

```text
mediaSlotModes?: Record<string, "off" | "canvas" | "default">
```

键使用稳定字段身份 `nodeId::fieldName`。未传入的槽位使用 `mediaDefaultMode`；旧配置没有这些字段时继续走现有逻辑。

画布节点元数据保存同样的 `mediaSlotModes`，使开关状态随项目保存和恢复。素材本体继续使用现有上游节点和引用数组，不复制进槽位配置。

## Bridge 检查与安全裁剪计划

Bridge 在检查工作流时已获取 API JSON 和 ComfyUI `/object_info`。对每个媒体加载字段执行以下分析：

1. 从加载节点沿下游连接遍历。
2. 中间节点的相关输入为必填时，该节点加入 `removeNodeIds`，继续沿其输出遍历。
3. 到达可选输入时，把该输入加入 `detachInputs`，停止该路径。
4. 动态输入如 `ref_images.ref_image_0` 按 `/object_info` 中的可选自动增长模板识别。
5. 任一路径到达输出节点、无法识别的输入定义、共享的必填业务分支，或形成循环时，分析失败；该字段不允许标记为可选。
6. 分支扇出时，所有路径都必须安全结束，才能生成裁剪计划。

计划必须包含原始加载节点。节点列表去重并稳定排序，便于保存、比较和测试。

## 运行数据流

1. 前端读取工作流可选媒体槽位和画布节点保存的模式。
2. `canvas` 模式的槽位按其真实 `sourceIndex`/`imageOrder` 生成稀疏引用数组；缺少素材时前端提示具体槽位。
3. 请求携带 `mediaSlotModes` 和现有参考素材数组。
4. 服务端解析字段时：
   - `off`：不生成覆盖值，也不执行 `required` 校验。
   - `canvas`：必须存在对应画布素材，沿用现有上传与类型校验。
   - `default`：不生成覆盖值，保留 API JSON 中的原始字段值。
5. 服务端把运行模式、字段配置和覆盖值一并发送给 Bridge。
6. Bridge 在工作流副本上依次执行：
   - 应用普通字段和媒体覆盖。
   - 对 `off` 槽位验证并执行保存的裁剪计划。
   - 删除 `removeNodeIds`，再删除 `detachInputs`。
   - 检查是否仍有连接指向已删除节点；存在则拒绝提交并指出节点。
7. Bridge 把最终 API JSON 提交给 ComfyUI，原始工作流文件不变。

当前 MiniMax H3 工作流的两个 `task_type` 字段配置为 `auto`。零参考素材时模型走 T2VA；有参考素材时由节点实现选择 Ref2VA 或 Hybrid。

## 校验与错误处理

- 可选槽位为 `canvas` 且缺少素材：`参考图片 2 已启用，但没有画布素材`。
- 可选槽位为 `default`：保留工作流默认文件，由 ComfyUI 校验文件是否存在；Bridge 不静默替换。
- 裁剪计划引用不存在的节点或字段：拒绝提交，提示重新拉取工作流参数。
- 裁剪后仍有悬空连接：拒绝提交，不向 ComfyUI 排队。
- 用户传入超过已配置槽位数量的素材：沿用现有容量错误。
- 非可选媒体字段：沿用现有必填和默认值行为。

错误发生在创建上游 ComfyUI 任务之前，不产生 GPU 队列和生成费用。

## 兼容性

- 新字段均可省略，现有数据库 JSON 无需迁移。
- 现有工作流在重新拉取参数前不会自动改变。
- RunningHub、普通 API 模型和非媒体字段不受影响。
- 工作流重新检查后，Bridge 重新生成裁剪计划；已失效的画布槽位状态按字段身份丢弃。

## 实现范围

- `model/setting.go`：工作流字段和裁剪计划结构。
- `service/workflow_mapping.go`、`service/workflow_task.go`：槽位模式解析、稀疏媒体映射和 Bridge 载荷。
- `canvas-agent/native/comfy-bridge/workflow.go`：可选分支分析、裁剪执行和悬空连接校验。
- `web/src/lib/workflow-channel.ts`：配置标准化和类型定义。
- `web/src/components/workflow/workflow-field-mapping-editor.tsx`：可选槽位配置。
- 画布生成节点及提交辅助函数：槽位开关、持久化和稀疏引用数组。
- `docs/progress/pending-test.md`：实现后记录可验证范围。

## 测试策略

### Go 服务测试

- 旧工作流字段无新配置时行为不变。
- `off` 跳过必填校验。
- `canvas` 缺失素材时返回具体槽位错误。
- `default` 不生成媒体覆盖。
- 稀疏图片和音频数组正确映射到后续槽位。

### Bridge 测试

- 加载节点直连可选输入。
- 加载节点经过缩放、预览等多层中间节点。
- 多条安全路径同时裁剪。
- 共享必填分支、输出节点和未知节点拒绝生成计划。
- 全部关闭、部分关闭和全部开启后的图均无悬空连接。
- 动态输入 `ref_images.ref_image_n` 和 `ref_audios.ref_audio_n` 正确识别。

### 前端测试

- 工作流配置只对安全槽位展示可选开关。
- 画布节点保存并恢复槽位模式。
- 关闭前序槽位后，后续画布素材仍绑定到正确下标。
- 全部关闭时允许提交；开启但缺少画布素材时阻止提交。

## 验收标准

- 当前 MiniMax H3 工作流在 6 张图片和 3 段音频全部关闭时，不再出现 `217::image 缺少值`，并能进入 ComfyUI 队列。
- 任意启用部分图片或音频时，只上传和连接对应槽位。
- 全部启用时行为与现有完整参考工作流一致。
- 原有未配置可选槽位的 ComfyUI 工作流测试保持通过。
- 运行中的桌面版升级后保留现有账号、Bridge、画布项目和工作流配置。
