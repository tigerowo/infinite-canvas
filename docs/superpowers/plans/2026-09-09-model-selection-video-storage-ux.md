# 模型选择、视频控件与后台配置收口

## 范围与验收

以用户批准的计划为准：模型按能力自动选择并拦截空模型；画布移除首尾帧设置；普通视频最长 15 秒；参数选中状态清晰；摄像机与参数窗口可用、可调整大小且不受画布缩放影响；NewAPI 只使用渠道地址；OSS 连接与访问策略在同一卡片中编辑。

保留历史任务解析、现有存储表及脱敏接口。不修改远程服务，不执行付费生成，不覆盖工作区已有修改。
