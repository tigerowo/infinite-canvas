# 微鑫画布前端交互收口计划

## 目标

针对玻璃界面上线前的实际使用问题，收口提示词库、画布触控操作、生成工作台和移动端交互。只修改前端及前端文档，不修改 NewAPI、OSS、数据库或后端接口。

## 实施项

- 提示词卡片限制摘要高度并对标签去重，详情弹窗继续显示完整原文。
- 画布节点、缩放手柄和连线统一使用 Pointer Events，避免触屏拖动被浏览器默认手势打断。
- 底部图片/视频工作台通过 ResizeObserver 动态计算结果区安全间距，展开参数时不遮挡结果。
- 画布提示词侧栏搜索使用防抖和单次服务端查询，分类只在展开时加载。
- 云端历史同步失败时保留本地记录并显示可重试提示。
- 补充引用候选菜单和侧栏标签的辅助技术语义，生成输入过滤输入法合成期间的 Enter。

## 验收

- TypeScript 类型检查、Next.js 生产构建和 `git diff --check` 通过。
- 已在当前登录浏览器检查提示词库：摘要显示为截断文本，详情入口保留，页面无重复 key 迹象。
- 未宣称真实生成、OSS/CDN 或生产部署已验证。
