# 管理员模型管理、存储配置与画布控件优化

## 目标

- 在管理员私有配置中提供独立的模型管理入口，支持拉取、预览、勾选合并，并由顶部保存设置统一提交。
- 将 S3 兼容存储的连接信息与文件访问策略按 Provider 组织，支持七牛、火山 TOS、Cloudflare R2 等通用配置。
- 保留旧 Provider 的历史读取能力，允许通过新增 Provider 后停用旧 Provider 的方式更换账号、桶或服务商。
- 让画布节点下方的提示词、图像、视频和音频设置面板跟随节点移动，但不随画布缩放改变视觉尺寸。

## 实现范围

- 管理员前端：模型管理表、模型拉取弹窗、S3 Provider 示例与访问策略卡片。
- 存储后端：Provider 连接保护继续生效，公开访问域名可独立变更；保留 `ext_storage_access` 和批量保存接口。
- 画布前端：节点面板通过 `document.body` Portal 使用屏幕坐标定位，并监听窗口、滚动、视口和节点尺寸变化。
- 不修改 NewAPI、外部 OSS/CDN 控制台、数据库表结构或普通用户个人存储范围。

## 验证清单

- Go：`go test ./...`。
- 前端：完整源码副本中的 TypeScript 检查、Bun 定向测试、Next.js 生产构建。
- 静态：`git diff --check`。
- 人工：管理员模型拉取与统一保存、多个 Provider 切换、画布缩放/平移/拖动下的浮层定位，以及小屏边缘避让。
