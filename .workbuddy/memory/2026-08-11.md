## 上传组件二轮修复（用户反馈）
- 叠加歪斜全倒一边的根因：整体 rotate(-6deg) 会叠加到子元素，+5deg 净剩 -1deg。修复：stackTransform 每张图补偿 +6deg（`rotate(tilt+6deg)`），净角度按 STACK_TILTS [5,-8,7,-6,9,-9] 左右交替
- 展开态上传框无动效：原填充/放大只在 count===0 生效。修复：新增 boxHovered state 挂在上传框自身，空态/展开态一致有 scale(1.1)+填充 activeBg；上传框 left 从 (count-1)*50 滑到 count*50（滑出+淡入，不再是原地淡入）

## 上传组件三轮修复（用户反馈）
- 展开后全是同一方向歪斜：原展开时 transform 置 none 只剩整体 -6deg。修复：stackTransform(index, expanded) 展开态也保留 rotate(tilt+6deg)，只去掉 translateX
- 输入区域固定避让：用户要求文字从 100px 位置开始输入。普通面板：编辑器 style paddingLeft:100 + placeholderIndent:88（提示文字 left=12+88=100）；配置面板：编辑器 paddingLeft:100 + 占位符 left:100。面板新增 hasUpload 常量统一判断（mode!=="audio" && onUploadImage）

## 上传组件四轮修复（用户反馈）
- 图片多了向右翘起溢出的根因：整体 rotate(-6deg) 作用在加宽整行上，行越宽右端翘越高。修复：展开时 wrapper 从 rotate(-6deg) 过渡到 rotate(0deg)，同时子图补偿角从 tilt+6 变为 tilt（净朝向不变，过渡连续），行被放平不溢出
- 展开单图悬停：hoveredIndex state；active 图 rotate(0)+scale(1.15)+投影+置顶，弹性缓动 cubic-bezier(0.34,1.56,0.64,1)；X 删除按钮在 tile 内部 right-1 top-1（不能放 tile 外，否则鼠标移向 X 时触发 mouseleave 闪烁）
- 删除接线：组件新增 onRemove prop → 面板 onRemoveImage → client page 复用 deleteNodes(new Set([nodeId]))（自动清理连线/存储/选中态）
